مستحيل — مشروع تجهيز APK لأندرويد

مهم: هذا مشروع بناء APK وليس ملف APK جاهزاً. تم إعداد سير عمل يبني APK تلقائياً باستخدام GitHub Actions.

الخطوات:
1. فك ضغط الملف.
2. أنشئ مستودعاً جديداً على GitHub وارفع كل محتويات المجلد إليه (Upload files).
3. افتح تبويب Actions في المستودع.
4. اختر Build Impossible APK ثم Run workflow.
5. انتظر حتى تصبح العملية خضراء، وافتح نتيجة التشغيل.
6. من قسم Artifacts حمّل Impossible-Khaled-APK.zip وفك ضغطه؛ بداخله app-debug.apk.
7. انقل APK إلى هاتف أندرويد وثبّته. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.
8. لإرساله لأصحابك، أرسل ملف app-debug.apk نفسه.

هذا APK تجريبي موقّع بمفتاح debug للبناء والتجربة، وليس إصدار متجر Google Play. احتفظ بالمفتاح نفسه إن أردت تحديث نفس التطبيق لاحقاً بإصدار موقع بشكل دائم.
